# Projeto 1 - Módulo 3

O script `Calculadora Mariane.py` foi desenvolvido para ser usado como uma calculadora. 

Para rodar este projeto de forma automatizada via terminal Linux/macOS, siga os passos abaixo:

1. Abra o terminal na pasta do projeto.
2. Dê permissão de execução para o arquivo `.sh` com o comando:
   ```bash
   chmod +x executar.sh
   ```
3. Execute o arquivo com o comando:
   ```bash
   ./executar.sh
   ```
