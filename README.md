# Projeto 1 - Módulo 3

O script `Calculadora Mariane.py` foi desenvolvido para ser usado como uma calculadora. É possivel fazer calculos de adição, subitração, divisão e multiplicação.
Primeiro você precisa incluir o número correspondente a operação que você quer fazer. e Depois incluir os números da operação. 

Para rodar este projeto de forma automatizada via terminal Linux/macOS, siga os passos abaixo:

1. Abra o terminal na pasta do projeto.
2. Dê permissão de execução para o arquivo `.sh` com o comando:
   ```bash
   chmod +x executar.sh
   ```
3. Execute o arquivo com o comando:
   ```bash
   ./executar.sh
   ```
