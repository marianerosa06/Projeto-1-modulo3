# Projeto 1 - Módulo 3

O script `Calculadora Mariane.py` foi desenvolvido para ser usado como uma calculadora. É possivel fazer calculos de adição, subtração, divisão e multiplicação.
Primeiro você precisa incluir o número correspondente a operação que você quer fazer (1-4). Depois incluir os números da operação. Se for uma operação impossivel, ele mostra uma mensagem de erro.

Para rodar este projeto de forma automatizada via terminal Linux/macOS, siga os passos abaixo:

1. Abra o terminal na pasta do projeto.
2. Execute o arquivo com o comando:
   ```bash
   bash executar.sh
   ```
